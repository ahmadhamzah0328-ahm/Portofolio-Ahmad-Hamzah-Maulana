# Portofolio Ahmad Hamzah Maulana

Website portofolio statis menggunakan HTML, CSS, dan JavaScript murni — tanpa build tools, framework, atau instalasi dependensi.

## Isi folder
- `index.html` — konten portofolio
- `styles.css` — desain responsif dan styling
- `script.js` — menu navigasi mobile dan tahun footer

## Menjalankan secara lokal
Cukup buka `index.html` di browser. Website ini juga bisa di-host langsung melalui GitHub Pages.

## Publikasi lewat GitHub Pages
1. Login ke GitHub dan buat repository baru, misalnya `portfolio-ahmad-hamzah-maulana`.
2. Unggah `index.html`, `styles.css`, dan `script.js` ke root repository (boleh unggah `README.md` juga).
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses deployment selesai. URL akan terlihat di halaman GitHub Pages, biasanya `https://USERNAME.github.io/portfolio-ahmad-hamzah-maulana/`.

## Sebelum dipublikasikan
- Periksa kembali nomor telepon dan email.
- Tambahkan tautan LinkedIn/GitHub bila ingin ditampilkan (CV sumber tidak mencantumkannya).
- Pastikan Anda nyaman menampilkan informasi kontak secara publik.
- Angka pengalaman dan proyek ditulis berdasarkan CV yang diberikan. Tidak ada tautan media sosial yang direkayasa.

## Catatan
Font DM Sans dan Space Grotesk diambil dari Google Fonts; jika koneksi internet tidak tersedia, browser akan menggunakan font sans-serif fallback.
